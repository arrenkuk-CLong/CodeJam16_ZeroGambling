# ZeroGambling

## If you love the thrill of uncertainty and want to have the same fun as gambling risk free, look no further than ZeroGambling!!!!!!!!

### About
ZeroGambling is a web-based game built with AI that helps people quit gambling. No in-app purchases, no real money involved! You can learn new skills and win in-game money that you can spend on the various games offered: 
* blackjack
* poker
* roulette
* slots
* baccarat
* slide game
* crash
* six-slot draw.
The platform teaches you the hidden mechanisms of these casino games you would encounter regularly at casinos that make them rigged and addicting every time you lose a round. You can gamble with various currencies, such as gems (main currency), learning progress of various skills or in-game XP you get from mastering skills. When you lose progress, you have to restart the grind and won't get any rewards on the way back. This web app is a MVP developed in 30 hours at McGill university's CodeJam hackathon, specifically its 16th edition. 

### Tech stacks
* Frontend: Next.js
* Backend: Django
* LLM: [Groq](https://console.groq.com/home)
* Database: PostgreSQL

The Next.js React frontend powers the UI of the app as well as the client side of the application. This includes rendering the UI, animating the minigames, sending requests and receiving responses from the backend. The Django backend is the backbone of the logic side of our application. It powers the CRUD of user data including username, password, email as well as skill progression, in-game currency and in-game items. It powers the logic of the minigames to prevent cheating from the client end. The LLM handles the skill tree generation as well as evaluation when levelling up skills, where each level up requires the user to correctly answer one or more questions that are also generated by the LLM. The database holds user data from login credentials to in-game currencies. 

### Societal impact
Gambling addiction is more of an issue in our society than ever. It can range from gambling real money to win it to abusing microtransactions in video games for loot boxes containing random rewards with odds for rare drops of in-game items. We make it equally addictive as the thrill of actually winning in gambling, but we allow the player to develop real world skills on the way and without risking real money.
